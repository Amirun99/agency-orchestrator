## 🧩 How It Works

agency-orchestrator uses a role-based workflow.

That means:
- one AI can act as a planner
- another can act as a researcher
- another can act as a writer
- another can act as a reviewer

Each role gets a clear job. The app then joins the results into one output.

This works well when you want:
- less back-and-forth
- more structure
- a full result from one prompt
- a repeatable process

## 📝 YAML Workflow Files

The app uses YAML files for setup. YAML is a plain text format that helps define steps in a workflow.

A typical workflow may include:
- task name
- role list
- model choice
- prompt text
- output format
- file paths

You can edit these files with:
- Notepad
- Notepad++
- VS Code
- any text editor

If you are new to this, start with a sample file and change only the task text and output path
